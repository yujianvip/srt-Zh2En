# 译声工作台 · 界面设计规范

## 设计方向

采用浅色字幕编辑台风格。用深色正文、克制的蓝色强调和稳定的分区支持长时间校对。应用 ui-ux-pro-max 的对比度、键盘可用性、渐进展示和布局稳定性规则，以及 frontend-design 的明确视觉层次与细节一致性原则。

## 布局

- 默认窗口 1360 × 880，最小 1050 × 740。
- 左侧设置区固定 320 px，可独立滚动；按导入、引擎、配音导出排列。
- “专注校对”收起设置区，保留“展开设置”入口；快捷键 Ctrl + Shift + F。
- 主区依次为标题、紧凑状态区、五列表格、三栏全文阅读区、两行播放器。
- 表格列顺序固定为：序号、时间码、中文原文、英文原文、英文译文。时间码不压缩，窄窗口提供横向滚动。
- 全文区分别显示中文原文、SRT 自带英文、英文译文；三栏都可编辑，长句自动换行并提供垂直滚动。点击“保存修改”或 Ctrl+S 后写入当前任务和表格；不覆盖导入的 SRT。切换字幕、引擎、载入文件、启动任务和关闭前检查未保存修改。
- 导入后选中第一条；支持上一条、下一条以及表格键盘选择。
- 试听区第一行显示文件与打开入口，第二行显示播放、停止、进度和时间，防止控件相互挤压。
- 翻译引擎区域固定高度，切换不改变主窗口尺寸。设置弹窗相对主窗口居中，支持 Esc 关闭。

## 颜色与字体

| 用途 | 色值 |
|---|---|
| 工作区 | #F6F8F9 |
| 设置与状态区 | #ECF2F5 |
| 字幕卡片 | #FFFFFF |
| 正文 | #1E2C35 |
| 辅助文字 | #4C5D67 |
| 主操作与可编辑区标识 | #16648F |
| 选中行 | #DCECF6 |
| 分隔线 | #CCD7DC |

使用 Microsoft YaHei UI：正文 11 pt，控件 10 pt，辅助文字 9 pt。数字标签使用 Consolas。行高 44 px。主操作“运行”使用实色按钮，其他操作使用浅色按钮。可编辑区同时用文字和边框区分，不只依赖颜色。输入区保留键盘焦点边框。

## 范围与验证

本轮仅调整界面。用用户提供的 122 条配对字幕验证五列显示、原文保留、编辑同步、逐条切换；在最小和默认窗口尺寸验证播放器可见性、引擎切换稳定性和专注模式展开。
