# 译声工作台

把中文 SRT 翻译成英文，逐句校对后生成**中英双语字幕**和**英文配音**。适合先在剪映完成视频，再把 SRT 与配音 WAV 导回剪映的工作流程。程序处理字幕与声音，不修改视频文件。

## 下载后开始使用

发布包文件名为 `srt-Zh2En-v1.0.3-package.zip`。发布到 [GitHub Releases](https://github.com/yujianvip/srt-Zh2En/releases) 后，可从那里下载并解压到可写入的文件夹。压缩包包含 `字幕翻译器-v1.0.exe` 和配音环境安装脚本。

**首次使用需要准备：**

1. 翻译二选一：安装并运行 [Ollama](https://ollama.com/)，且已下载一个可用模型；或准备 DeepL API Key。
2. 如需生成英文配音：安装 **Python 3.11**，电脑需有支持 CUDA 的 NVIDIA 显卡。双击解压目录中的 `setup_voxcpm.bat`，等待出现“配音环境安装完成”。
3. 打开 `字幕翻译器-v1.0.exe`，点击“检测配音模型”。如果模型尚未下载，按提示下载 VoxCPM2。下载完成后，后续使用通常无需重复安装。

只做字幕翻译和校对时，可以先跳过配音环境的安装。发布包不包含 Ollama、翻译模型、VoxCPM2 模型或配音环境；首次安装和下载需要网络及数 GB 可用磁盘空间。

## 翻译并生成成品

1. 点击“选择 SRT 文件”，或把剪映导出的 SRT 拖进窗口。
2. 选择“本地模型”或“DeepL API”。使用 Ollama 时刷新模型列表并选模型；如果服务未启动，程序会提示启用已安装的 Ollama。使用 DeepL 时输入 API Key。
3. 点击“开始翻译”。在逐句对照区检查中文原文、原有英文和新译文。修改后点击“保存修改”，也可按 `Ctrl+S`。
4. 可选：在“参考声音”中选择一段 WAV。留空时使用统一的默认音色。确认输出文件夹，点击“生成双语字幕与英文配音”。
5. 完成后在窗口底部试听 WAV，或通过完成提示打开输出目录。把双语 SRT 和英文 WAV 导入剪映并检查时间对齐。

“保存修改”只更新**当前打开的任务**；点击“生成双语字幕与英文配音”成功后，校对结果才写入输出 SRT。翻译完成会播放提示音；电脑连续空闲 30 秒后，程序会自动开始生成成品。要先校对，请在倒计时结束前开始编辑，或取消倒计时。

## 导入什么样的 SRT

| 输入 | 用途 | 注意事项 |
| --- | --- | --- |
| 纯中文 SRT | 翻译、校对、生成双语字幕与英文配音 | 每条字幕带时间码 |
| 逐条中英双语 SRT | 对照已有英文，重新翻译或校对 | 每条字幕的中文行在英文行上方 |
| 前半中文、后半英文的 SRT | 读取剪映合并导出的双语字幕 | 中英文条数和对应时间码必须一致 |
| 纯英文 SRT | 导入后逐句查看 | 缺少中文原文，不能运行中文翻译 |

逐条双语字幕示例：

```srt
1
00:00:00,066 --> 00:00:01,166
大家好，这里是遇见 AI。
Hello everyone, this is Meet AI.
```

文件需为 UTF-8 编码，大小不超过 20 MB。单条字幕可以有多行，但双语字幕的中文行必须全部位于英文行之前。

## 输出什么文件

每次生成一对同时间戳文件，例如：

```text
26-10-23 15-42-08-中英双语字幕-Ollama.srt
26-10-23 15-42-08-英文配音-Ollama.wav
```

如果同一时间戳已经存在，会为这对文件一起追加序号。SRT 每条字幕先中文、后英文，并沿用原字幕时间码。配音略长时会适度加速；超过可接受范围时提示缩短英文，不会让后续字幕顺延。导入剪映后仍需试听检查声音与画面的配合。

## 翻译与配音依赖

- **Ollama**：默认服务地址为 `http://localhost:11434`，默认模型名为 `qwen3.5:9b`，均可在界面中调整。程序通过 Ollama API 翻译；当前版本需要已安装的 Ollama 服务，不能直接读取硬盘上的 Ollama 模型文件。服务未启动时可按提示启用。
- **DeepL**：需要可用的 API Key 和网络连接。Key 仅用于当前运行，不写入设置文件。使用 DeepL 不需要 Ollama。
- **VoxCPM2**：`setup_voxcpm.bat` 在程序同目录创建独立的 `.venv-tts`，模型下载到 `.model-cache`。这些文件应与 EXE 保持在同一目录下。普通设置保存在 `%LOCALAPPDATA%\字幕翻译器\settings.json`。

机器译文仍应核对人名、产品名、界面文字和专业术语。

## 遇到问题

| 现象 | 处理方法 |
| --- | --- |
| 读取不到 Ollama 模型 | 确认已安装 Ollama、服务已启动、模型已下载；在界面检查地址并刷新模型列表。 |
| 提示缺少中文原文 | 当前导入的是纯英文 SRT；改用含中文的 SRT 再运行翻译。 |
| 提示尚未安装配音环境 | 在 EXE 同目录运行 `setup_voxcpm.bat`；脚本要求 Python 3.11。 |
| 配音模型尚未下载 | 点击“检测配音模型”，按提示下载。 |
| 提示某组英文过长 | 缩短对应英文，再生成配音；程序会保留原字幕时间码。 |

## 从源码构建与发布

Windows 11、Python 3.11 环境下运行 `build.bat`，在项目根目录生成 `字幕翻译器-v1.0.exe`。如需直接运行源码，先在项目 `.venv` 中安装 `requirements.txt`，再运行 `run_app.py`；英文配音仍需运行 `setup_voxcpm.bat`。

构建完成后，运行 `.venv\Scripts\python.exe packaging\make_release.py` 生成 GitHub Release ZIP 和 SHA-256 校验文件。当前自动更新从 Release ZIP 提取新 EXE，保留本机已安装的配音环境和模型。若配音依赖发生变化，需要重新运行安装脚本。
